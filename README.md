# Waleed Raza — GitHub Pages portfolio

Static academic and technical portfolio for [Waleed Raza](https://raza-waleed.github.io/).

The site presents research in Advanced Air Mobility, UAS integration, aviation safety, route optimization, simulation, signal processing, and underwater acoustics. Its content is kept consistent with [waleedraza.dev](https://waleedraza.dev/) and the [Google Sites portfolio](https://sites.google.com/view/waleed-raza/).

## Files

- `index.html` — complete portfolio, projects, publications, experience, awards, service, and contact information
- `cv.html` — printable curriculum vitae
- `journey.html` — interactive geospatial career journey
- `style.css` — shared portfolio design and responsive layout
- `reveal.js` and `method-scroller.js` — progressive animations
- `sitemap.xml` and `robots.txt` — search-engine discovery

GitHub Pages deploys the repository from the root of the `main` branch.
